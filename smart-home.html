Smart Home Backend

A personal, non-commercial home automation server.

Smart Home Backend is a private application that runs on a single server in the owner's home. It controls and monitors that household's own devices: lighting and relays, energy meters, media players, cameras, and heating.

Google Nest integration

The application connects to the Google Smart Device Management API to read the state of, and control, a Nest thermostat that the account owner has explicitly authorised. It uses this to display the current temperature and heating status, to change the mode and target temperature, and to keep a local history of heating activity.

Who can use it

This application is not offered to the public. It has a single user — its owner — and is not distributed, sold, or operated as a service.
