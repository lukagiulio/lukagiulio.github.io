Privacy Policy

Smart Home Backend — last updated 28 September 2026

Smart Home Backend is a personal, non-commercial application operated by a single individual for their own household. It has no other users.

What data is accessed

With the account owner's explicit authorisation, the application uses the Google Smart Device Management API to read and control their own Nest thermostat. The data accessed is limited to:

  • ambient temperature and humidity;
  • thermostat mode and target temperature;
  • heating/cooling activity status;
  • device connectivity status and device identifier.

No contacts, location history, email, calendar, photographs, camera or microphone streams, or any other Google account data are requested or accessed.

How the data is used

Solely to display the state of the household's heating, to change the thermostat mode and target temperature at the owner's request, and to compute local statistics such as heating runtime.

Where the data is stored

All data is stored locally on a private server inside the owner's home. It is not transmitted to any third party, not uploaded to any cloud service, not used for advertising, not sold, and not shared. The application has no analytics, no telemetry, and no external integrations beyond the Google API it reads from.

Retention

Readings are retained locally for historical charts and are deleted at the owner's discretion by removing the local database.

Access by others

No one other than the owner has access. The application is reachable only from the home network and requires authentication.

Revoking access

Access granted to this application can be withdrawn at any time from Google Account → Security → Third-party apps & services, or from the Google Home app. Revoking access immediately stops all data collection.

Google API Services User Data Policy

This application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
